Argus detector for CVAT

Approved first delivery · 3 September 2026

Deploy the six-class Argus RF-DETR model as a normal CVAT detector. Run it on a complete frame or draw a native region of interest. Each invocation performs one inference pass. Sliced inference is deferred.

Annotation workflow

  1. Open AI Tools → Detectors and select Argus Outdoor v1.
  2. Map its six output classes to task labels and choose a confidence threshold.
  3. Run on the frame, or enable the detector region of interest and draw a rectangle.
  4. Review the returned instance masks. CVAT places ROI predictions back in frame coordinates.

Scope and practical limits

The new Nuclio function uses the existing detector interface, label mapping, threshold control and native ROI support. A large full image is resized to 504 pixels on its longest side; small defects can benefit from a tighter ROI. There is no automatic tiling in this delivery.

Verification and release

The Argus function is deployed and healthy following explicit deployment approval. All 105 Argus tests pass in the bridge environment; the shared RF-DETR suite passes 253 tests with one optional dependency skip. Real GPU checks match the bridge reference exactly for masks and transformed inputs on a full 5280 × 3956 photo and a 1024 × 801 crop. A temporary Nuclio processor is healthy, and the actual CVAT adapter correctly maps labels, converts dense masks to RLE, and translates ROI coordinates with zero database queries or annotation writes.

Deployed image: cvat.rfdetr.argus.outdoor.v1:single-pass-20260903. Live CVAT gateway checks passed for full-image and ROI inference, label mapping and mask placement. All 24 existing containers remained unchanged. These checks used a fixture image and in-memory task metadata; an authenticated browser annotation smoke test was not performed. Sliced inference remains deferred.

Reproducibility

The checkpoint and both source repositories are pinned. Runtime source is bundled from Git rather than mounted from the active training checkout. Only the copied checkpoint is mounted read-only. The function fails startup on a checkpoint hash or architecture mismatch.
