Adaptive Frame Tag Contrast

CVAT UI design · approved 2026-09-05

Executive summary

Frame tags currently receive a label-colored background while Ant Design forces their text and close icon to a light color. White and other light labels therefore become unreadable. The fix will reuse CVAT's existing computeTextColor() utility, improve its black/white choice using WCAG relative luminance, and explicitly apply its foreground to both the pill text and close icon.

Scope: top-left frame tags in annotation and tag-annotation workspaces, including ground-truth tags. Label schema colors and annotation data do not change.

Options considered

Recommended

Shared contrast utility and targeted wiring

Choose black or white by relative-luminance contrast, then set it directly on each frame tag and close icon. This keeps one shared algorithm and is immune to Ant Design's generated style order.

Global Ant Tag override

Change every custom-color Ant tag. Broader consistency, but risks unrelated screens and preset-status tags.

New shared Tag wrapper

Centralize future colored tags. Useful only if several screens need migration; unnecessary for this defect.

Component behavior

  1. Validate a six-digit hexadecimal color and calculate its standard sRGB relative luminance.
  2. Select whichever of black or white produces greater WCAG contrast; retain white as the fallback for malformed input.
  3. For each visible frame tag, pass tag.label.color to the shared computeTextColor().
  4. Apply the result as the tag's inline text color.
  5. For removable tags, render the normal close glyph with the same inline color so Ant Design's light-icon rule cannot override it.
  6. Keep existing highlighting, filtering, removal, ground-truth rendering, and label background behavior intact.

Verification

  • A test-first component harness must fail against the current source because foreground props are absent.
  • The harness must prove black text and close icon on white/light backgrounds, white foreground on purple/dark backgrounds, and correct choices for saturated CVAT palette greens and reds.
  • A real React/JSDOM/Ant Design integration must check rendered styles, SVG currentColor, and close dispatch whenever the optional DOM dependency is available.
  • TypeScript, targeted lint, the existing tag-annotation Cypress spec, and a production UI build must remain clean.
  • A Chromium candidate harness must inspect computed colors for both the pill text and close icon.
