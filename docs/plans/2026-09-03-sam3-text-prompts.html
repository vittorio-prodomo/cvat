SAM3 text prompts in CVAT

Describe objects, preview separate masks, then accept them.

3 September 2026 · CVAT fork · Deployed and verified at 10:58 CEST

The existing Segment Anything 3 interactor now supports a Text mode for the current frame or a selected region. Each matching instance becomes a separate preview mask using the selected task label. The deployment includes the earlier optional-box-to-points fix.

Live

The SAM3 function and UI are deployed. Text, ROI, and point inference passed through the live CVAT gateway; the public UI bundle matches the verified candidate. The other 22 containers are unchanged.

Using Text mode

  1. Save current work and hard-refresh CVAT with Ctrl+Shift+R.
  2. Open AI Tools → Interactors → Segment Anything 3 and choose Text.
  3. Select the task label and enter a short phrase describing one concept, such as red circles. Optionally restrict inference to an ROI.
  4. Click Find masks. Review the separate instances and adjust the confidence threshold if needed.
  5. Click Done to add the displayed masks, then use CVAT's normal Save. Esc discards the preview.

Accepted behavior

ControlBehavior
Text promptOne trimmed, nonempty phrase, up to 256 characters. All returned instances use the selected task label.
ConfidenceInitial display threshold 0.5; slider range 0.2–0.9. The processor returns candidates from 0.2. Lowering the threshold can reveal weaker or overlapping predictions.
ROICVAT crops the frame for inference and translates masks back to full-image coordinates.
PreviewDone accepts the displayed masks separately. Esc, changing frame/job, or switching tools discards the active preview and invalidates late responses.
RepeatThe N shortcut restores the last started interactor setup, including its prompt, mode, label, and ROI.
Points / boxAvailable as the existing visual mode, including optional starting box followed by point refinement.

This first version does not refine individual text-result masks with point prompts. Text and visual prompts are separate modes.

Implementation

Capability, request, and response contracts

The function advertises text_prompt as a text field in its existing extra_params_schema. The UI exposes Text mode only for functions declaring that capability. Existing backend extra-parameter forwarding and ROI handling carry the request.

SAM3 uses the same loaded model and checkpoint for its interactive predictor and image processor. Each text request receives fresh image state. The handler returns separate masks as tight-bounds row-major RLE with confidence attributes; visual requests preserve the legacy single-mask response.

Empty, non-string, oversized, or mixed text/visual requests return HTTP 400. Native bfloat16 scores are converted to float before NumPy conversion.
