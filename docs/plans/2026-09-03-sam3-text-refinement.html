SAM3 text mask refinement

Text finds instances; positive and negative points refine one selected instance.

3 September 2026 · Deployed and verified at 11:58 CEST

The user approved extending the existing text preview with per-mask point refinement. The existing model and checkpoint provide the needed mask and point inputs.

Workflow

  1. Enter a phrase and click Find masks.
  2. Click a preview mask, or choose it in the mask selector when results overlap.
  3. Add positive points with the left button and negative points with the right button. The selected mask is highlighted.
  4. Use Back to masks to refine another result, or Done to accept displayed masks. Save normally in CVAT.

Behavior

Only the selected mask changes. Labels and text detection confidence stay attached to their original instances. Removing all current points restores the mask used at the beginning of that refinement visit. Returning to a previously refined object starts from its confirmed result.

Esc discards the entire preview. Frame/job changes cancel it. Late responses cannot replace another mask or resurrect a discarded session. Done accepts the currently displayed masks and cancels any unfinished request.

Integration

A capability flag in the text parameter schema activates the UI. The selected mask is sent as validated run-length encoding with accumulated points. Each request is self-contained. ROI mask coordinates are converted to the same cropped-image coordinate system already used by CVAT's point prompts.

Model handoff

The Nuclio handler converts the seed mask to signed logits at the interactive predictor's actual mask-input size, then predicts one instance from the mask and positive/negative points. No checkpoint change or shared inference session is needed. The text discovery and visual refinement scores remain distinct.

Verification and delivery

Meaningful regression tests cover selection, points, stale responses, confidence, ROI, Done/Esc, and the existing text/visual flows. A real GPU probe checks the handoff. Browser verification includes actual canvas selection and point drawing. Independent specification and quality reviews passed.
