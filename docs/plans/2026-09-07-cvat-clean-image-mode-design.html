CVAT clean-image mode

A reversible shortcut for viewing the source frame without any CVAT annotation or review overlay.

7 September 2026 · CVAT fork · Implemented and locally checked in isolated feature worktree; browser run pending

Executive summary

Add a frontend-only clean-image mode to image annotation jobs. A registered, user-rebindable shortcut—Shift+H by default—temporarily suppresses every annotation and review overlay while leaving the source bitmap visible. The mode never changes annotation data or existing visibility preferences, remains active while navigating frames, and restores the previous presentation exactly when toggled off.

Approved behavior

The reviewer gets a fast, nuclear visibility switch: source image only, then one keypress to bring every CVAT overlay back.

Goals and boundaries

Goals

  • Provide one fast command for inspecting the unobstructed image.
  • Hide annotation geometry, annotation text, tags, issue regions, conflict overlays, and ground-truth comparison overlays together.
  • Preserve every underlying annotation, review item, and user visibility preference.
  • Keep the mode active while moving between frames in the same job.
  • Expose the command through CVAT's normal shortcut registry so each user can rebind it.

Non-goals

  • No annotation deletion, mutation, server request, autosave event, or audit-log entry.
  • No persistent job or account setting. Reloading or closing the job resets the mode.
  • No change to the source bitmap's zoom, rotation, smoothing, brightness, contrast, saturation, or other image filters.
  • No replacement for per-object visibility, the existing T H command, or the issues eye control.

Options considered

Selected

Dedicated transient mode

A single runtime flag suppresses rendering at the overlay boundaries.

  • Exact restoration
  • No annotation-state churn
  • Easy to extend when CVAT adds overlay types

Reuse existing hide actions

Hide all objects and issues, then remember and restore each prior state.

  • Reuses existing actions
  • Fragile with already-hidden objects and mixed review settings

Ad hoc CSS hiding

Apply display rules to currently known overlay selectors.

  • Small initial patch
  • Easy for new or rerendered overlays to bypass

Shortcut behavior

Shift+H is only the default. The command appears in CVAT's shortcut list and uses the existing per-user rebinding and conflict-resolution mechanism. The status indicator displays the user's current binding rather than hard-coding the default.

State and action

The annotation canvas state owns cleanImageMode and transient detectorOperationIDs; the operation list derives the simple detectorInferencePending guard consumed by the control. Starting inference synchronously exits clean before awaiting the server. Direct-create, tags-only, and Preview Done await the annotation write Promise under their operation guard. Cancellation before a write releases the request token; a write already started remains guarded until success or failure, even after cancellation or unmount. Core writes are not cancelable. Each finalizer releases only its own ID, so older component/job work cannot clear newer guards. Close, logout, and reload reset the transient state.

Shortcut registration

Register TOGGLE_CLEAN_IMAGE_MODE at annotation-page scope with Shift+H as its default sequence. Mount a single handler at the annotation-page boundary so it works in standard and review workspaces without duplicate registrations. The normal shortcuts UI remains the source of truth for rebinding.

Canvas boundary

The 2D canvas configuration carries an explicit clean-image presentation flag. Text, masks, bitmap, grid, and attachment roots are hidden with their prior visibility restored on exit. The content SVG stays visible as the interaction plane for pointer events and coordinate mapping. A scoped canvas CSS class suppresses its current and future children, except the temporary ROI zoom selection rectangle. This preserves real drag-to-zoom while annotation geometry and review overlays remain hidden. Cancelling ROI zoom removes the selection rectangle and all its pointer listeners.

React and review boundaries

Frame tags and canvas context menus read the same flag and omit their visual output. Stateful issue and new-issue dialogs, plus issue labels, remain mounted through portals inside the visibility-hidden attachment board, preserving unsent comments, descriptions, and component identity. No review dialog is moved outside that hidden board. If a retained focused control receives Enter, the shared review mutation boundary exits clean synchronously before creating, commenting, resolving, reopening, or deleting an issue. Legacy plain create/start/submit-review actions also clear clean mode. They preserve the issues eye, resolved-issue preference, ground-truth setting, and conflict records. The transient highlighted conflict is cleared while hidden, and populated conflict labels are mapped again from visible objects on restoration.

Restoration

Disabling the flag causes the canvas and React overlay components to render from their current authoritative state. Objects that were manually hidden stay hidden; visible objects return; issue filters, active layer settings, and ground-truth preferences resume exactly as before.

Interaction safeguards

  • Refuse activation whenever drawing, shape editing, mask editing, issue-region selection, an interactor session, or a detector preview owns temporary canvas content, and while detector inference is pending (including results committed directly without preview).
  • Do not cancel, finish, or mutate an in-progress operation as a side effect of the shortcut.
  • Show a concise notice: “Finish or cancel the current canvas operation before entering clean-image mode.”
  • While clean mode is active, pan, zoom, frame navigation, and image inspection remain enabled.
  • If a command begins an annotation or review operation, dispatch clean exit before invoking its 2D canvas start API. Cancellation remains first, and slice captures its target before the Redux control transition clears selection. The shared draw popover retains existing 3D ordering.
  • One-shot mutations such as Delete, lock, hidden, occluded, pinned, keyframe, outside, color, and z-order changes exit clean through their shared annotation action boundary before core mutation. Bulk updates/removal, creation, propagation, geometry operations, and undo/redo use the same policy. When clean mode is already disabled, this boundary dispatches nothing.
  • Saving while clean mode is active saves the same annotations as usual because the feature changes presentation only.

Deployment and rollback

The feature changes only cvat-ui and the browser-side canvas packages. It requires rebuilding and recreating the UI service; no CVAT server migration, database change, API change, or Nuclio deployment is required. Rollback consists of restoring the previous UI image.
